黒瀬 玲夜（くろせ れいや）

Error Code: Midnight

受信した言葉じゃない。君が見たものを返して。

GenreアニメOP風
Energy158 BPM
Mood緊迫、疾走、冷たい雨、理解の接続
Colors濃紺、黒、青紫、深紅、冷たい白

黒瀬玲夜は、雨天高層区の境界監視員。判断と移動は速いが、短い符号だけで意図まで共有できたと思い込み、返答がずれると一人で経路を変えてしまう。違う階層を見ていた相棒へ、責める前に問い返す。観測した事実と行動案を分け、互いの言葉で理解を返し合ったとき、二人は初めて同じ経路図を持って走り出す。
